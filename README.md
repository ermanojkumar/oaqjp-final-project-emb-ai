# Final Project

This project analyzes the emotions expressed in a given text using the IBM Watson NLP Emotion Prediction API.

## Features

- Detects emotions from input text
- Uses Python and Flask
- Calls the Watson NLP Emotion API

## Installation

```bash
pip install -r requirements.txt
python3 -m pip install requests
```

## Usage

```bash
python server.py
```
